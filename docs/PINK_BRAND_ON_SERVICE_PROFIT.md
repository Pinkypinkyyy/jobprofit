# Service Profit uses Pink branding

Service Profit is a **line of Pink Accounting**, not a second firm and not a second visual identity.

| Layer | Locked value |
|---|---|
| Logo | Official pink wordmark (lowercase **pink**, `#ED1651` triangle). Same files as working papers. |
| Colour | Black `#0E0E12` · White · Pink `#ED1651` as a thin accent only. Never a fill. |
| Type | Montserrat on the site. Segoe UI 10pt on documents and email. |
| Offer name | Service Profit (the line). Pink Accounting (the firm). |
| Forbidden | A Service Profit wordmark-as-logo. Blue, copper, teal, or any other palette. IBM Plex. Hospitality copy on this site. |

Black-led treatment is the industrial read: black nav, black footer, black buttons, trade photography. The logo and the 2px pink rule stay so a client still recognises Pink.
